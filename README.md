# 🛡️ GuardianX AI

## Predict. Protect. Prevent.

GuardianX AI is an AI-powered smart factory monitoring platform developed for Micro, Small, and Medium Enterprises (MSMEs). It provides real-time monitoring, predictive maintenance, energy analytics, worker safety monitoring, and an AI-powered factory assistant through an interactive Streamlit dashboard.

---

## Features

- 🛠 Guardian Predict – AI-Based Predictive Maintenance
- ⚡ Guardian Energy – Real-Time Energy Monitoring
- 📅 Guardian Care – Predictive Maintenance Scheduler
- 🦺 Guardian Safe – Worker Safety Monitoring Prototype
- 🤖 GuardianX Assistant – Offline AI Factory Copilot

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## Disclaimer

Guardian Safe currently demonstrates a prototype workflow using simulated AI analysis. It is designed to support future integration with real computer vision models such as YOLO for PPE detection and worker safety monitoring.
